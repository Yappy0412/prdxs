# RE 0 : 序章（意図）

**「天才」と「天才構造」について**  
まず言っておかなければならないのは、天才という言葉について。それは、結果であり、外部の評価であるという事。  
「花瓶に差された花」「鉢植えで成長した果実」こそが天才の証明だが、「花瓶」「鉢植え」の内側が美しく秀逸であっても内部構造についてはよく分らないものだ。  
本書は私個人の経験や探求から、あえて、その内部「構造」を定義・言語化し、そこに至るための道筋の「一つ」を提示するものだ。

別の切り口からも表現すれば、非社交的社交性から逃れられない古びたOSをカーネルから書き換えようというシステムでもある。  
まずは、各状態の模式図とその解説する。  
その上で、どのようなアップデートを実現するのか、仮説と実践について提案をする。
